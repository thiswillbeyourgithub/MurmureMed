# MurmureMed

MurmureMed est un fork de [Murmure](https://github.com/Kieirra/murmure), une application de reconnaissance vocale 100 % locale.

Son but est de porter dans une application facile à installer les fonctionnalités du **mode médical de ParakeetWeb**, déjà utilisable aujourd'hui : [http://parakeetweb.olicorne.org/?mode=med](http://parakeetweb.olicorne.org/?mode=med)

ParakeetWeb fonctionne dès maintenant, et plutôt bien, dans n'importe quel navigateur. Mais il reste limité au navigateur. MurmureMed doit en faire une application installable en quelques clics, pour pouvoir dicter directement dans **n'importe quelle application de l'ordinateur** (logiciel métier, traitement de texte, messagerie, etc.).

En attendant que MurmureMed soit prêt, utilisez ParakeetWeb.
